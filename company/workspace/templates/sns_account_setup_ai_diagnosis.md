# 役割
AI業務改善診断ビジネスのSNSアカウント作成テンプレートです。

# 目的
各SNSのプロフィール、固定投稿、リンク、投稿方針を統一し、LPへの導線を作ることです。

# 使い方
SNSアカウント作成時に、表示名、ID、プロフィール文、固定投稿、リンクをコピーして設定します。

# 保存先
`company/workspace/templates/sns_account_setup_ai_diagnosis.md`

各SNSの初期設定に使える文面が揃っていること。

## YouTube

### チャンネル名
0から始めるAI活用

### 概要欄
AIを仕事に使いたいけれど、何から始めればいいかわからない個人事業主・小規模事業者向けのチャンネルです。

ChatGPTを触っただけで終わらせず、業務整理、時短、発信、資料作成、問い合わせ対応、マニュアル作成に使う方法を発信します。

無料AI活用チェック:
https://stylishdeeb4.github.io/AI_company/

### 初期動画案
1. AI導入はツール選びから始めるな
2. ChatGPTを触っただけで終わる人の共通点
3. 個人事業主がAIで減らせる作業10選

## X / Threads

### プロフィール文
AIを仕事に使いたい個人事業主・小規模事業者へ。業務整理、時短、発信、マニュアル作成のAI活用を発信。無料AI活用チェックはこちら。

### 固定投稿
AI導入は、ツール選びより先に「業務の棚卸し」から。

メール返信、投稿作成、資料作成、議事録、FAQ。
まずは毎週くり返している作業を確認すると、AIに任せる場所が見えてきます。

無料AI活用チェックはこちら。
https://stylishdeeb4.github.io/AI_company/
