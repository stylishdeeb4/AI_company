# 作業手順

必ず以下の順番で作業してください。

## 1. main_managerが依頼内容を整理する

まず、依頼内容を整理してください。

整理する項目は以下です。

* 制作物の種類
* ページの目的
* ターゲット
* ターゲットの悩み
* ターゲットが得たい未来
* 主要CTA
* 必要ページ
* 実装方法
* 成果物
* 不足情報
* 仮置きで進める情報

不足情報がある場合でも、作業を止めないでください。
不明点は「仮設定」として最善案を置いたうえで進めてください。

## 2. researcherが市場・競合・ユーザーを整理する

`researcher`は、LP・HPの土台となる情報を整理してください。

以下を出してください。

* ターゲットの悩み
* ターゲットの検索意図
* ターゲットが不安に感じること
* ターゲットが比較するポイント
* 競合サイトでよく使われる構成
* 差別化できるポイント
* 訴求軸
* SEOキーワード候補
* FAQ候補

不確かな情報は断定せず、「仮説」と明記してください。

## 4. content_makerがページ本文・コピーを作る

`content_maker`は、ページに掲載する文章を作成してください。

作成する内容は以下です。

* メインキャッチコピー
* サブコピー
* CTA文言
* 各セクションの見出し
* 各セクションの本文
* ボタン文言
* FAQ
* お客様の声の仮文
* 実績紹介の仮文
* プロフィール文
* 会社概要文
* 問い合わせ前の不安を消す文章

コピー作成時は以下を守ってください。

* 誰に向けたページか一目でわかる
* 何が得られるか明確にする
* ベネフィットを先に伝える
* 専門用語を使いすぎない
* 1文を長くしすぎない
* CTAの直前に不安解消を入れる
* 誇大表現を避ける
* 実績がない場合は、嘘の実績を作らない
* 仮文は「仮」と明記する

以下を作成してください。

* メインキーワード

* H1

* OGPタイトル

* FAQ構造
* 内部リンク案
* ブログ記事案
* Google検索で表示されたときの見え方

* 色のコントラストが弱すぎないか

* 法務リスクがないか
