# 作業ログ: AI社員 RULES / MEMORY 整備

## 役割
各AI社員の作業ルールと記憶ファイルを整備した履歴を記録します。

## 目的
誰が、何を、どの基準で担当するかを明確にし、AI会社の運営を安定させるためです。

## 使い方
各AI社員のルール更新履歴として参照します。

## 保存先
`company/workspace/logs/work_logs/20260607_agent_rules_memory.md`

## 完了条件
対象エージェント、編集ファイル、変更内容、次に追加すべき作業が分かること。

## 対象エージェント
- main_manager
- content_maker
- researcher
- thumbnail_designer
- legal_checker
- accountant
- secretary

## 編集内容
- 各 `RULES.md` に、役割、ミッションとの接続、基本姿勢、作業手順、成果物の保存先、品質チェック項目、禁止事項、失敗時の対応を追加。
- 各 `MEMORY.md` に、このエージェントが覚えておくべきこと、過去の重要な学習、よくあるミス、改善されたルール、ユーザーの好み、成果物の傾向を追加。
- 各AI社員のキャラクター性を、仕事の姿勢・価値観・判断基準として反映。

## 次の作業
各AI社員の `skills/` 配下に、実務テンプレートと手順書を追加する。
