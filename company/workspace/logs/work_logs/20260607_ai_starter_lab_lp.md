# 品質チェック
- title / description / OGPを設定した。
- H1とH2構造を設定した。
- alt属性を設定した。
- フォームにlabelと必須項目を設定した。
- CTAを複数箇所に配置した。
- スマホ対応CSSを設定した。
- 実績とお客様の声は仮文として明記した。
- 誇大表現を避けた。
