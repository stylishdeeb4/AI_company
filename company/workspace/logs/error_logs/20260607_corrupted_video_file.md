# エラーログ: 動画ファイル破損

## 役割
納品した動画ファイルが破損していた問題の原因、修正、再発防止策を記録します。

## 目的
今後の動画納品で、再生互換性の低い形式を避けるためです。

## 使い方
動画ファイルを生成・納品する前の確認項目として参照します。

## 保存先
`company/workspace/logs/error_logs/20260607_corrupted_video_file.md`

## 完了条件
何が起きたか、本来どうすべきだったか、原因、修正内容、再発防止策が明記されていること。

# 何が起きたか
前回納品した `20260607_short_ai_first_task_video.avi` が、ユーザー環境で破損ファイルとして扱われた。

# 本来どうすべきだったか
動画ファイルは、納品前に再生互換性が高い形式で生成し、可能な範囲でヘッダー・サイズ・再生可能性を確認すべきだった。

# なぜミスが起きたか
- ffmpegが使えない環境で、MJPEGと音声ストリームを含むAVIを手書き生成した。
- AVIの音声ストリームやインデックス構造が、プレイヤーによっては互換性不足になる可能性があった。
- ファイルサイズと存在確認は行ったが、実再生確認までできていなかった。

# 修正内容
- 生成方式を、音声なしの単純なVideo-only AVIに変更。
- 圧縮方式をMJPEGから非圧縮DIBに変更。
- 解像度を360x640、10fps、60秒に変更し、互換性を優先。
- カバー画像の文字切れも再確認した。

# 再発防止策
- ffmpegが使えない場合は、音声ストリーム付きの手書きAVIを避ける。
- まずVideo-onlyの単純形式で納品する。
- MP4納品が必要な場合は、ffmpeg等のエンコーダを使える環境を用意する。
- 納品前にヘッダー、ファイルサイズ、カバー画像、ログを確認する。
