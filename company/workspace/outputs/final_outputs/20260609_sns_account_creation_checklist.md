# 役割
YouTube / X / Instagram / TikTok のアカウント作成チェックリストです。

# 目的
SNSアカウント作成時に、入力内容、設定項目、確認事項を迷わず進めるためです。

# 使い方
各SNSのアカウント作成画面を開き、このファイルの内容をコピーして設定します。メール認証、電話番号認証、ログイン、規約同意はユーザー本人が行います。

# 保存先
`company/workspace/outputs/final_outputs/20260609_sns_account_creation_checklist.md`

# 完了条件
4つのSNSアカウントが作成され、プロフィール、リンク、初期投稿準備が完了していること。

## 重要ルール

- パスワードはこのファイルに保存しない。
- 認証コードはこのファイルに保存しない。
- 電話番号や本人確認情報はユーザー本人が入力する。
- 利用規約と年齢・本人確認に関する項目はユーザー本人が確認する。
- アカウント作成後、2段階認証を設定する。
