## 依頼内容の整理
- 制作物: 無料AI活用チェック質問フォーム、AI業務改善診断LP
- ページ目的: 無料チェック回答、個別相談、ミニ診断への誘導
- ターゲット: 個人事業主、1〜10名規模の小規模事業者
- 主なCTA: 無料AI活用チェックを受ける
- 実装方法: HTML / CSS / JavaScript
- 不足情報: 実際の問い合わせ先、予約リンク、プライバシーポリシーURL
- 仮設定: メールリンクは `example@example.com`

## ページ戦略
- 悩み: AIを触ったが仕事に活かせていない。何から始めるべきかわからない。
- 得たい未来: 自分の業務でAIが効く場所がわかり、すぐ使えるテンプレートが手に入る。
- 訴求軸: ツール導入ではなく、業務整理から始めるAI導入。
- 差別化: 業務棚卸し、プロンプト、利用ルール、マニュアルまで一体で支援。
- CTA導線: 無料チェック → 診断タイプ表示 → 個別相談 → ミニ診断

## LP構成
| セクション | 目的 | 掲載内容 | CTA |
| --- | --- | --- | --- |
| ファーストビュー | 誰向けか即理解 | メインコピー、特徴、画像 | 無料チェック |
| よくある悩み | 共感形成 | 使い道不明、毎回手作業、ルールなし | なし |
| 無料チェック | 入力行動 | フォーム、診断結果表示 | 診断結果表示 |
| サービス内容 | 価値説明 | 棚卸し、AI化、テンプレート、ルール | なし |
| 料金 | 有料商品理解 | 無料、ミニ診断、スターターキット | 相談導線 |
| FAQ | 不安解消 | 初心者、機密情報、業種、効果 | なし |
| CTA | 行動促進 | 無料チェック誘導 | 無料チェック |

## デザイン方針
- スマホファースト
- 信頼感を出す白背景と濃い文字
- メインカラーはティール、アクセントにアンバーとコーラル
- カードは8px角丸
- CTAはページ上部、フォーム、最下部に配置
- 画像は業務整理とAI診断のダッシュボード感を表現

## リスクチェック
- 売上保証はしない。
- 専門領域は専門家確認が必要と明記。
- 機密情報や個人情報の詳細入力を避ける注意書きを配置。
- 静的フォームのため、実運用接続が必要と明記。
