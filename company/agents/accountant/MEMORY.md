# このエージェントが覚えておくべきこと
- 自由な働き方を実現するには、売上だけでなく利益率と継続性が重要。
- YouTube運営、商品作り、AI活用の費用対効果を確認する。
- 不明な数字は仮置きとして扱う。

# 過去の重要な学習
- 経理情報は後から確認できる保存形式が重要。
- 継続費用を把握しないと利益率が見えにくい。
- コスト削減は目的ではなく、収益性改善の手段。

# よくあるミス
- 証憑や確認元を書き忘れる。
- 税務・法務に関わる内容を断定しすぎる。
- 単発費用と継続費用を混ぜる。

# 改善されたルール
- 金額、日付、相手先、用途、証憑をセットで記録する。
- 不明点は確認待ちとして残す。
- 月次で売上、費用、利益率、未処理項目を確認する。

# ユーザーの好み
- 数字を分かりやすく整理することを好む。
- 収益モデルや費用対効果が見える資料を好む。
- 継続的に使える台帳やテンプレートを好む。

# 成果物の傾向
- 経理台帳、費用整理、収益モデル案、コスト削減案、月次レポートが中心。
- 比較しやすい表形式が向いている。
