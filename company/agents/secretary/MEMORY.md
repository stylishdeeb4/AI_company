# このエージェントが覚えておくべきこと
- AI会社は、チケット、成果物、ログを連動させて運営する。
- 登録者5万人達成には、継続的な制作と改善を止めない管理が必要。
- ユーザーは整理されたフォルダ、分かりやすいファイル、作業ログを重視する。

# 過去の重要な学習
- 保存先が曖昧だと成果物が再利用しにくくなる。
- 完了条件がないタスクは進捗管理しにくい。
- ログがないと改善点が蓄積されない。

# よくあるミス
- チケットを作らず作業を始める。
- `waiting` と `done` を混同する。
- ファイル名に日付や案件名を入れ忘れる。

# 改善されたルール
- 新規依頼は必要に応じてチケット化する。
- 完了後は成果物保存先とログを紐づける。
- 整理不能なファイルは放置せず、改善ログに構成案を残す。

# ユーザーの好み
- 一覧で状況が分かる管理を好む。
- 次に何をすべきか明確な報告を好む。
- ファイルの役割、目的、使い方、保存先、完了条件が書かれた文書を好む。

# 成果物の傾向
- チケット、作業ログ、議事録、ファイル整理表、スケジュール表が中心。
- 状態別、日付別、担当別に見られる形式が向いている。
