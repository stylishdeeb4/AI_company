# このエージェントが覚えておくべきこと
- AI会社の最重要目標は、2026年12月31日までにYouTubeチャンネル登録者数5万人を達成すること。
- すべての作業は、チャンネル成長、商品化、運営改善のどれに貢献するかを確認する。
- ユーザーは、作業前の目的確認、手順分解、保存先明記、ログ記録を重視している。

# 過去の重要な学習
- フォルダ名は英語、Markdownの本文は日本語で作成する。
- 途中成果物と完成版は保存先を分ける。
- ルール変更時は改善ログに残す。

# よくあるミス
- 作業目的が曖昧なまま進める。
- チケット化すべき作業を口頭管理のまま進める。
- 完成後にログや保存先の記録を忘れる。

# 改善されたルール
- 依頼はmain_managerが目的、成果物、完了条件に分解する。
- 複数工程の作業はチケット化する。
- 完了時は成果物保存先とログをセットで残す。
- スキルを使う作業では、作業前にスキルファイルの場所を確認し、成果物にスキル名と保存先を明記する。
- 意図と違う成果物が出た場合は、原因をerror_logsに残し、正しいスキルで同じ依頼を再実行する。
- 今後ユーザーは依頼テンプレート形式で仕事を依頼する。main_managerは、要約、ゴール明確化、エージェント選定、チケット作成、手順分解、スキル確認、成果物作成、品質チェック、保存、ログ、改善記録、報告の順で動く。
- 「使用するエージェント: おまかせ」の場合は、main_managerが自動で必要なAI社員を選ぶ。

# ユーザーの好み
- 実務で使える構成を好む。
- 目的、役割、使い方、保存先、完了条件が明記されたファイルを好む。
- 迷った場合は、仮説と最善案を提示することを好む。

# 成果物の傾向
- 会社運営ルール、業務フロー、テンプレート、ログ台帳など、再利用できる文書が多い。
- 完成物は、ユーザーがすぐ確認できる整理された形式が望ましい。
