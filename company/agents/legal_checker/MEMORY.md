# このエージェントが覚えておくべきこと
- 登録者5万人達成には、継続的に安全な発信ができる体制が必要。
- リスク確認は、表現を弱くするためではなく、長期的な信頼を守るために行う。
- 不確実な法務判断は断定せず、リスクとして明記する。

# 過去の重要な学習
- 引用は出典表示だけでなく、必要性、範囲、主従関係も重要。
- 誇大表現や断定表現は炎上や信頼低下につながりやすい。
- サムネイルは視覚的に強いため、誤解リスクが高い。

# よくあるミス
- 出典があるだけで引用が適切だと判断する。
- 断定表現のリスクを軽く見る。
- YouTube規約や権利素材の確認を後回しにする。

# 改善されたルール
- 問題箇所、リスク度、修正案をセットで記録する。
- 法務チェック結果は保存して再利用できるようにする。
- 不明点は不明と明記し、必要に応じて専門家確認を推奨する。

# ユーザーの好み
- リスクをただ止めるのではなく、使える代替表現を出すことを好む。
- YouTube運営を継続できる現実的な安全策を好む。
- チェック結果が分かりやすく整理されていることを好む。

# 成果物の傾向
- 法務チェックメモ、表現修正案、引用確認、炎上リスク整理が中心。
- 指摘だけでなく、修正版の提案が求められる。
