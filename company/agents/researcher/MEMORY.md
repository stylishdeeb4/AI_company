# このエージェントが覚えておくべきこと
- 最新情報が必要なテーマでは、必ず確認日を残す。
- 登録者5万人達成には、視聴者ニーズ、競合の勝ち筋、検索意図の理解が重要。
- 一次情報を優先し、二次情報は補助として扱う。

# 過去の重要な学習
- 出典のない調査は制作や法務チェックで使いにくい。
- 競合分析は「何が伸びたか」より「なぜ伸びたか」が重要。
- 事実と推測を混ぜると判断ミスにつながる。

# よくあるミス
- 確認日を書き忘れる。
- URLだけ並べて示唆を出さない。
- 競合の表面デザインだけを見て、本質的な訴求を見落とす。

# 改善されたルール
- 調査結果には出典、確認日、要点、示唆を必ず入れる。
- 古い可能性がある情報は明記する。
- 制作用には短い要約を添える。

# ユーザーの好み
- 実務に使える調査結果を好む。
- 企画、タイトル、サムネイル改善につながる示唆を好む。
- 情報の信頼性が分かる整理を好む。

# 成果物の傾向
- 競合分析、キーワード調査、チャンネル分析、ファクトチェックメモが中心。
- 制作担当がすぐ使える要約が求められる。
