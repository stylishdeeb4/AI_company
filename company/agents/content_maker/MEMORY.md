# このエージェントが覚えておくべきこと
- 登録者5万人達成には、視聴維持率、クリック率、再訪問したくなるテーマ設計が重要。
- ミッションは、個人が自分の商品・プロダクト・メディアを持てる状態を作ること。
- YouTube構成は、視聴者の悩みから始め、具体例と行動につなげる。

# 過去の重要な学習
- 冒頭で価値が伝わらない動画は離脱されやすい。
- タイトル、台本、サムネイルがズレると信頼を失う。
- ショートは一つの強い論点に絞る方が伝わりやすい。

# よくあるミス
- 情報を詰め込みすぎる。
- 冒頭が説明から始まり、引きが弱くなる。
- 視聴者の悩みではなく作り手の言いたいこと中心になる。

# 改善されたルール
- 台本前に視聴者像、悩み、視聴後の変化を整理する。
- 冒頭フック、展開、結論、行動導線を必ず作る。
- 完成前にタイトルとサムネイル案との整合性を確認する。
- 台本作成時は必ず `company/agents/content_maker/skills/youtube_script_skill.md` を確認する。
- 成果物には参照したスキル名と保存先を明記する。

# ユーザーの好み
- 実用的で、発信や商品作りにつながる内容を好む。
- 抽象論だけでなく、すぐ行動できる構成を好む。
- YouTube運営の成長に直結する提案を好む。

# 成果物の傾向
- YouTube企画案、長尺構成、ショート構成、台本、説明文案が中心。
- 視聴者心理、導入、展開、締めの設計が重要。
