# スキル名
LP・HP企画構成コピー作成スキル

# 役割
LPまたはHP制作において、ページ戦略、情報設計、セールスコピー、本文、FAQ、CTA文言を作成するためのスキルです。

# 目的
単に見た目のよいWebページではなく、ターゲットの行動につながる導線、分かりやすい情報設計、誇大表現を避けた実用的なLP・HP本文を作ることです。

# 使用前確認
作業前に以下を確認します。

- `company/AGENTS.md`
- `company/agents/content_maker/RULES.md`
- このファイル `company/agents/content_maker/skills/lp_hp_creation_skill.md`

成果物の冒頭に、使用スキル名と保存先を明記します。

# 入力情報
- LP / HPの種別
- 制作するページの種類
- サービス・商品名
- サービス・商品の概要
- ターゲット
- ターゲットの悩み
- ターゲットが得たい未来
- ページの目的
- 主なCTA
- 希望する雰囲気
- 参考サイト
- 使用したい色
- 必要なページ
- 掲載したい情報
- 使いたい画像・素材
- 実装方法
- 納品してほしい成果物

不足情報がある場合は作業を止めず、「仮設定」として最善案を置きます。

# 作業手順
1. 依頼内容を整理する
   - 制作物の種類、ページ目的、ターゲット、CTA、必要ページ、実装方法、成果物を整理します。
   - 不足情報と仮設定を分けて書きます。

2. ターゲットの悩みを整理する
   - 今困っていること
   - 申し込み前に不安に感じること
   - 比較するときに見るポイント
   - 得たい未来

3. 訴求設計を作る
   - 誰に売るのか
   - 何を訴求するのか
   - なぜ今必要なのか
   - なぜこのサービスなのか
   - 競合ではなく選ばれる理由
   - CTAまでの流れ

4. LP / HP構成を作る
   - LPの場合は1ページで、問題提起からCTAまで自然につなげます。
   - HPの場合はトップ、サービス、実績、料金、FAQ、会社概要、問い合わせなどに分けます。

5. ファーストビュー案を作る
   - メインキャッチ
   - サブコピー
   - CTAボタン
   - 補足文
   - 信頼要素
   - 背景画像案

6. セクション別コピーを作る
   - 見出し
   - 本文
   - 箇条書き
   - CTA
   - 画像案

7. FAQを作る
   - 申し込み前の不安を解消する質問を作ります。
   - 料金、流れ、納期、キャンセル、サポート、実績、対象者を含めます。

8. プロフィール・会社概要文を作る
   - 実績が不明な場合は仮文と明記します。
   - 嘘の実績は作りません。

9. SEO担当へ渡す情報を整理する
   - メインキーワード
   - 関連キーワード候補
   - H1 / H2候補
   - FAQ候補

10. 品質チェックを行う
   - ターゲットに刺さるか
   - CTAが明確か
   - 文章が長すぎないか
   - 誇大表現がないか
   - 仮文が仮と明記されているか

# LP構成の基本形
1. ファーストビュー
2. 共感・問題提起
3. 放置した場合の損失
4. 解決策の提示
5. サービス紹介
6. 選ばれる理由
7. 実績・事例
8. お客様の声
9. 料金・プラン
10. 利用の流れ
11. よくある質問
12. 不安解消
13. CTA
14. 会社情報・運営者情報
15. フッター

# HP構成の基本形
1. トップページ
2. サービス紹介
3. 強み
4. 実績
5. お客様の声
6. 料金
7. よくある質問
8. お知らせ / ブログ
9. 会社概要 / プロフィール
10. お問い合わせ
11. プライバシーポリシー
12. 特定商取引法に基づく表記

# コピー作成ルール
- 誰に向けたページか一目で分かるようにする。
- 何が得られるかを明確にする。
- ベネフィットを先に伝える。
- 専門用語を使いすぎない。
- 1文を長くしすぎない。
- CTAの直前に不安解消を入れる。
- 誇大表現を避ける。
- 実績がない場合は、嘘の実績を作らない。
- 仮文は「仮」と明記する。

# 品質基準
- ターゲットと目的が明確である。
- ファーストビューで何のページか分かる。
- CTAが明確である。
- セールスコピーが自然である。
- 誇大表現がない。
- 実績やお客様の声が仮の場合は、仮と明記されている。
- 制作・実装に使える粒度になっている。
