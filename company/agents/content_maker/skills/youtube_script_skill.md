# スキル名
YouTube台本作成スキル

# 目的
視聴者の興味を引き、最後まで見られやすいYouTube台本を作る。

# 入力情報
ユーザーから受け取る情報は以下です。

- 動画テーマ
- 想定視聴者
- 動画尺
- 参考チャンネル
- 伝えたい結論
- 商品・サービスへの導線
- NG表現
- 必要な出典

不足している情報がある場合は、作業を止めずに仮説を置きます。ただし、法務・出典・商品導線に関わる不明点は、仮置きであることを明記します。

# 作業手順
0. 使用スキルの確認
   - 作業前に、このファイル `company/agents/content_maker/skills/youtube_script_skill.md` を使用することを確認します。
   - 成果物の冒頭に「使用スキル名」と「スキル保存先」を明記します。
   - 古いスキルや記憶ではなく、このファイルの手順と出力形式を優先します。

1. テーマを理解する
   - 動画で扱う中心テーマを一文で整理します。
   - 登録者5万人達成にどう貢献するかを確認します。

2. 想定視聴者を定義する
   - 年齢、職業、悩み、知識レベル、視聴シーンを仮定します。
   - 既に分かっている指定があれば優先します。

3. 視聴者の悩み・欲求・疑問を整理する
   - 視聴者が動画をクリックする理由を整理します。
   - 視聴前の悩みと視聴後の変化を明確にします。

4. 動画のゴールを決める
   - 視聴者に理解してほしいこと、行動してほしいことを決めます。
   - 商品・サービス導線がある場合は、自然な接続点を設計します。

5. 冒頭のフックを3案作る
   - 問題提起型、意外性型、結論先出し型など複数の切り口で作ります。
   - 冒頭5秒で見る理由が伝わるかを確認します。

6. 構成案を作る
   - 導入、本編、具体例、まとめ、CTAの流れを作ります。
   - 長尺動画では視聴維持率を意識し、途中に転換点を入れます。
   - ショート動画では論点を一つに絞ります。

7. 本文台本を作る
   - 話し言葉で自然に書きます。
   - 専門用語を使う場合は、短く説明を入れます。
   - 断定しすぎる表現や誇大表現を避けます。

8. 視聴維持率を高める仕掛けを入れる
   - 先が気になる予告を入れます。
   - 途中で問いかけ、具体例、比較、失敗例を入れます。
   - 同じ調子が続かないように展開を作ります。

9. 最後にCTAを入れる
   - チャンネル登録、コメント、概要欄確認、商品・サービスへの導線を自然に入れます。
   - 押し売りではなく、視聴者の次の行動として提案します。

10. 品質チェックを行う
   - 品質基準に沿って、冒頭、流れ、根拠、表現、CTA、保存形式を確認します。
   - 必要に応じてresearcherやlegal_checkerに確認を依頼します。

11. 成果物を保存する
   - 途中案は `company/workspace/outputs/agent_outputs/` に保存します。
   - 完成版は `company/workspace/outputs/final_outputs/` に保存します。

# 品質基準
- 使用スキル名とスキル保存先が成果物に明記されていること。
- 冒頭5秒で興味を引けること。
- 視聴者の悩みに直結していること。
- 結論がわかりやすいこと。
- 話の流れに違和感がないこと。
- 離脱ポイントが少ないこと。
- 専門用語を使いすぎないこと。
- 誇大表現がないこと。
- 次の行動につながること。

# 意図と違う成果物が出た場合
1. 何がズレたかを整理します。
2. 原因を `company/workspace/logs/error_logs/` に記録します。
3. 改善策を `company/workspace/logs/improvement_logs/` に記録します。
4. このスキルを再確認し、同じ依頼を改めて実行します。
