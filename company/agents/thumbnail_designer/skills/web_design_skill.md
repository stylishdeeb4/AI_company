# スキル名
LP・HP Webデザイン設計スキル

# 役割
LPまたはHP制作において、ワイヤーフレーム、ファーストビュー、CTA配置、スマホ表示、配色、余白、画像配置などのデザイン指示を作るスキルです。

# 目的
スマホで読みやすく、CTAが見つけやすく、ターゲットの行動につながるWebデザイン設計を作ることです。

# 使用前確認
作業前に以下を確認します。

- `company/AGENTS.md`
- `company/agents/thumbnail_designer/RULES.md`
- このファイル `company/agents/thumbnail_designer/skills/web_design_skill.md`

成果物の冒頭に、使用スキル名と保存先を明記します。

# 入力情報
- LP / HPの種別
- ページ目的
- ターゲット
- 希望する雰囲気
- 参考サイト
- 使用したい色
- 必要ページ
- セクション構成
- CTA
- 画像・素材の有無
- 実装方法

# 作業手順
1. ページ目的を確認する
   - 問い合わせ、LINE登録、資料請求、購入など、目的を明確にします。

2. ターゲットと雰囲気を確認する
   - 信頼感、やさしい、シンプル、高級感、ポップ、未来感などを整理します。

3. ワイヤーフレームを作る
   - セクションごとの配置をテキストで作ります。
   - CTAの位置を明記します。

4. ファーストビューを設計する
   - 誰向けか
   - 何が得られるか
   - 何をすればよいか
   - 信頼要素
   - 背景画像案

5. CTA配置を設計する
   - ファーストビュー
   - 悩み・解決策の後
   - 料金・FAQの後
   - ページ最下部

6. スマホ表示を設計する
   - 1カラムを基本にする。
   - ボタンを押しやすくする。
   - 文字サイズと余白を確保する。
   - 情報を詰め込みすぎない。

7. 配色を決める
   - メインカラー
   - サブカラー
   - アクセントカラー
   - 背景色
   - 文字色
   - コントラスト

8. フォント方針を決める
   - 読みやすさを優先する。
   - 見出しと本文の差を明確にする。
   - 小さすぎる文字を避ける。

9. 画像配置と生成プロンプトを作る
   - ファーストビュー画像
   - サービス説明画像
   - 実績・お客様の声用画像
   - CTA前の安心感を出す画像

10. 離脱防止の工夫を入れる
   - 長すぎる文章を分割する。
   - アイコン、カード、表、FAQを使う。
   - CTA直前に不安解消を置く。

# デザインで重視すること
- スマホファースト
- ファーストビューで誰向けか伝わる
- CTAが見つけやすい
- 余白がある
- 文字が読みやすい
- 重要な情報が埋もれない
- 背景と文字のコントラストを確保する
- 読み込みが重くなりすぎない
- 信頼感を出す要素を入れる
- 視線誘導を意識する
