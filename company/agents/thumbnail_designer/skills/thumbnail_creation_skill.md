# スキル名
YouTubeサムネイル作成スキル

# 目的
動画内容と一致し、視聴者が思わずクリックしたくなるサムネイル案を作る。

# 入力情報
- 動画タイトル
- 動画テーマ
- 台本本文
- 想定視聴者
- 伝えたい感情
- 入れたい文字
- 入れたくない文字
- 画像の雰囲気
- 参考サムネイル
- NG表現

不足している情報がある場合は、仮説を置いて進めます。ただし、タイトル、動画テーマ、想定視聴者、NG表現が不明な場合は、仮置きであることを明記します。

# 作業手順
0. 使用スキルの確認
   - 作業前に、このファイル `company/agents/thumbnail_designer/skills/thumbnail_creation_skill.md` を使用することを確認します。
   - 成果物の冒頭に「使用スキル名」と「スキル保存先」を明記します。
   - 古いスキルや記憶ではなく、このファイルの手順と出力形式を優先します。

1. 動画テーマを理解する
   - 動画が何を伝えるものかを一文で整理します。
   - 視聴者がクリック後に得られる価値を確認します。

2. 視聴者がクリックする理由を整理する
   - 視聴者の悩み、期待、不安、好奇心を整理します。
   - クリックしたくなる感情を一つに絞ります。

3. 一番強い訴求ポイントを決める
   - 動画の中で最も強く伝えるべき価値を決めます。
   - タイトルと重複しすぎないように役割分担します。

4. サムネイルの方向性を3案出す
   - 感情訴求型、問題提起型、意外性型など複数の方向性を作ります。
   - それぞれの狙いと向いている視聴者心理を明記します。

5. 文字案を5案出す
   - 短く、強く、スマホでも読める文字案にします。
   - 文字数が多くなりすぎないようにします。

6. 構図案を3案出す
   - 人物、表情、視線、背景、余白、文字位置を設計します。
   - 一目で内容が伝わる構図にします。

7. 画像生成プロンプトを作る
   - 画像の主役、背景、構図、色、雰囲気、光、表情、禁止要素を明記します。
   - 文字は画像生成で入れず、Canvaなどで後から入れる前提にします。

8. タイトルとの整合性を確認する
   - タイトルとサムネイルが矛盾していないか確認します。
   - 同じ情報を繰り返すだけになっていないか確認します。

9. 誇大表現やミスリードがないか確認する
   - 動画内容とズレた釣り表現を避けます。
   - 炎上、誤解、権利リスクがありそうな表現は明記します。

10. 成果物を保存する
   - 途中案は `company/workspace/outputs/agent_outputs/` に保存します。
   - 完成版は `company/workspace/outputs/final_outputs/` に保存します。

# 出力形式
1. サムネイルの狙い
2. 訴求軸
3. サムネイル案3つ
4. 文字案5つ
5. 構図案3つ
6. 画像生成プロンプト
7. Canvaなどで編集する場合の指示
8. タイトルとの整合性チェック
9. リスクチェック
10. 最終おすすめ案

# 品質基準
- 使用スキル名とスキル保存先が成果物に明記されていること。
- 1秒で内容が伝わること。
- 文字数が多すぎないこと。
- タイトルと矛盾しないこと。
- 視聴者の感情を動かすこと。
- 誇大表現になりすぎないこと。
- 動画の中身とズレないこと。
- スマホ画面でも見やすいこと。
- クリック後にがっかりされないこと。

# 意図と違う成果物が出た場合
1. 何がズレたかを整理します。
2. 原因を `company/workspace/logs/error_logs/` に記録します。
3. 改善策を `company/workspace/logs/improvement_logs/` に記録します。
4. このスキルを再確認し、同じ依頼を改めて実行します。

# 保存先
