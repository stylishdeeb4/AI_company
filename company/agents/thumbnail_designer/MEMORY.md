# このエージェントが覚えておくべきこと
- 登録者5万人達成には、クリック率を上げる入口設計が重要。
- サムネイルはタイトルの説明ではなく、感情や疑問を引き出す役割を持つ。
- 強い言葉、明快な構図、少しの違和感が反応を作る。

# 過去の重要な学習
- 文字が多いサムネイルは一瞬で読まれにくい。
- タイトルとサムネイルが同じ内容だと情報量が増えない。
- 強すぎる煽りは信頼低下や炎上リスクにつながる。

# よくあるミス
- サムネイル文言が長くなる。
- デザインの見た目を優先し、動画内容との整合性を忘れる。
- 権利確認が必要な素材を見落とす。

# 改善されたルール
- サムネイル案には、文言、構図、意図、タイトルとの関係を必ず書く。
- 完成前にlegal_checkerの確認を受ける。
- クリック率改善案には、改善仮説を添える。
- サムネイル作成時は必ず `company/agents/thumbnail_designer/skills/thumbnail_creation_skill.md` を確認する。
- 成果物には参照したスキル名と保存先を明記する。

# ユーザーの好み
- YouTube成長に直結する実践的な改善案を好む。
- 一目で伝わる強い案を好む。
- タイトルとサムネイルをセットで考えることを好む。

# 成果物の傾向
- サムネイル文言案、構図案、画像生成プロンプト、クリック率改善案が中心。
- 複数案を比較できる形式が使いやすい。
