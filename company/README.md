# AI会社 README

## 役割
このファイルは、ユーザー専用AI会社の使い方を説明する入口です。

## 目的
AI会社の目的、最重要目標、主要フォルダ、作業の進め方をすぐ理解できるようにします。

## 使い方
1. まず `company/AGENTS.md` を確認します。
2. 会社の目的は `company/docs/mission.md` で確認します。
3. 作業手順は `company/docs/workflow.md` に沿って進めます。
4. 成果物の完成前に `company/docs/quality_standards.md` を確認します。
5. 担当AI社員は `company/agents/` 配下の `MEMORY.md` と `RULES.md` を確認します。
6. 途中成果物は `agent_outputs`、完成版は `final_outputs` に保存します。
7. 作業後はログを残します。

## 保存先
`company/README.md`

## 完了条件
このREADMEを読めば、AI会社の目的、使い方、主要フォルダ、次に確認すべきファイルが分かること。

## 最重要目標
2026年12月31日までに、YouTubeチャンネル登録者数5万人を達成すること。

## ミッション
フリーランスがクライアントワークに依存せず、会社員が会社に依存しなくてもいいように、自分の商品・プロダクト・メディアを持てる状態を作る。

そのために、YouTubeとAIを活用し、個人が自由な働き方を実現できるように、発信・企画・商品作り・運営改善を行う。

## 主要フォルダ
| フォルダ | 役割 |
| --- | --- |
| `company/agents/` | 各AI社員の記憶、ルール、スキル |
| `company/workspace/tickets/` | 作業チケット |
| `company/workspace/outputs/agent_outputs/` | 途中成果物 |
| `company/workspace/outputs/final_outputs/` | ユーザー確認用の完成版 |
| `company/workspace/references/` | 参考資料、リサーチ結果 |
| `company/workspace/logs/work_logs/` | 作業ログ |
| `company/workspace/logs/error_logs/` | エラー、ミス、再発防止ログ |
| `company/workspace/logs/improvement_logs/` | 改善案、改善実施ログ |
| `company/workspace/templates/` | よく使うテンプレート |
| `company/docs/` | ミッション、業務フロー、品質基準 |

## 基本運用
- 依頼はmain_managerが整理します。
- 必要に応じてチケットを作ります。
- 担当AI社員が作業します。
- 途中成果物は `agent_outputs` に保存します。
- 完成版は `final_outputs` に保存します。
- 作業ログ、エラーログ、改善ログを残します。
